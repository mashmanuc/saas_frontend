    ✨ Колекція прикладів

    Як користуватися

    Вводь по одному виразу в кожне поле зліва.

    • Функція: y = x^2, y = sin(x), x = y^2
    • Власна функція: f(x) = x^2 + 1, далі y = f(x-2), g(x) = f(f(x))
    • Кускова функція: y = {x < 0: -x, x >= 0: x^2} — пара умова: значення через кому, останнє без умови = інакше
    • Факторіал n! (працює й для дробів через Γ), остача % або mod(a,b)
    • Логарифми: ln(x) — натуральний, log(x) — десятковий, з основою — log_2 x або log_2(x), log_a(x)
    • Сума Σ та добуток Π: sum(i, 1, 10, i) = 55, product(i, 1, 5, i) = 120; з x у тілі — графік ряду, напр. ряд Фур'є y = sum(n, 1, 20, sin(n x)/n) (можна писати символами Σ, Π)
    • Рекурентна послідовність: задай базові випадки з числовим індексом F(0) = 0, F(1) = 1 і загальну формулу F(n) = F(n-1) + F(n-2) — послідовність може посилатися сама на себе
    • Графік послідовності: plot(F(n), n, 0, 12) — точки (0, F(0)), (1, F(1)), … зі стовпчиками; працює з будь-якою послідовністю чи функцією, напр. plot(n^2, n, 0, 8)
    • L-системи: вбудовані koch(4), dragon(12), sierpinski(5), hilbert(5), plant(5); довільна форма: lsystem("F", "F->F+F--F+F", 4, 60) — аксіома, правила, ітерації, кут (°)
    • Фрактали: mandelbrot() — множина Мандельброта; julia(-0.8, 0.156) — множина Юлії; панорамуй та масштабуй мишкою
    • Рівняння (неявне): x^2 + y^2 = 9, (x-2)^2+(y-1)^2=4
    • Нерівність (заливка області): y < x^2, x^2+y^2 <= 9, y >= sin(x)
    • Обмеження області у фігурних дужках: y = x^2 {x > 0}, y = sin(x) {-3 < x < 3} — кілька дужок поспіль додаються разом
    • Полярна крива: r = 4 cos(3θ), r = 1 + 2 cos(θ), r = θ (кут θ або theta)
    • Параметрична крива: (cos(t), sin(t)), (3 sin(3t), 3 sin(2t)) — пара з вільним t; діапазон t задається під виразом (типово 0…2π)
    • Логіка and / or / not у нерівностях і умовах: y > 0 and y < x^2, x < -2 or x > 2, {x > 0 and y > 0}
    • Точка: (2, 3)
    • Таблиця даних: кнопка ⊞ на панелі — ввід точок (x, y) у клітинки; відображення точками, лінією або обома
    • Регресія: у таблиці обери модель (лінійна, квадратична, кубічна, експонента, логарифм, степенева) — підгонка по точках, крива та рівняння з R²
    • Ctrl + перетягування кривої з параметром на полотні змінює значення цього параметра (повзунок рухається разом)
    • Невідома буква (напр. a) → з'явиться кнопка +a: створює повзунок з анімацією ▶
    • Полотно: тягни — рух, колесо — масштаб, кнопки праворуч — +/−/дім
    • Кружок зліва: клік — сховати, правий клік — колір
