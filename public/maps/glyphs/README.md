# Гліфи підписів історичної карти (закон §9 v1.78)

Рушій карт малює підписи (держави, річки, міста, моря) з гліфів у форматі PBF. Вони лежать тут, локально:
карта не робить зовнішніх запитів.

- Шрифт: **Open Sans Semibold** (Apache License 2.0 / SIL OFL 1.1).
- Гліфи — з демонабору MapLibre (`https://demotiles.maplibre.org/style.json` → `glyphs`), завантажено 30.10.2026
  для стенда атласу (`saas_docs/plans/north_ship/HANDOFF_FEYA_ATLAS_2_5D_2026-10-30.md`).
- Лише потрібні діапазони: `0-255` (латиниця), `256-511` (латиниця розширена), `1024-1279` (кирилиця),
  `8192-8447` (’ – …). Нова назва з символом поза ними — спершу додати діапазон сюди.
